### Задание 5 **(2)**

*Напишите программу на С++, которая прочитает натуральное число* **n**, *создаст вектор
из* **n** *элементов, прочитает значения элементов, добавит последний элемент вектора к каждому элементу 
(в том числе и к последнему), найдет и выведет количество положительных и отрицательных элементов вектора
после изменения. Из циклов в программе можно использовать только циклы по коллекции.*


Программа сохраняет последний элемент в last, чтобы прибавить его исходное значение к каждому числу, включая последнее. Запись auto &x позволяет менять сам элемент вектора. После сложения программа проверяет его знак. Например, [-3, 0, 2] превращается в [-1, 2, 4]. Выводится 2 1, потому что положительных чисел два, а отрицательное одно.

```
int main() {
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto &x : a)
        cin >> x;

    const auto last = a.back();
    int positive = 0, negative = 0;
    for (auto &x : a) {
        x += last;
        if (x > 0) ++positive;
        if (x < 0) ++negative;
    }
    cout << positive << " " << negative << endl;
}
```

### Задание 6 **(3)**

*Представим, что в некотором будущем стандарте* **С++** *появится конструкция*
```
forc(i, from, to)
```
*которая будет раскрываться в следующий код.*
```
{
   int __i = from, __n=to;
   for(const int &i= __i; i < __n; __i++) {
      ...
   }
}
```
*Чем эта конструкция отличается от стандартного цикла* **for**? *Укажите два основных различия.
Напишите программы для демонстрации этих различий.*

*Написанные программы сохраните в папку с номером задания.*


Первое различие касается счётчика. В обычном for переменную i можно увеличить прямо в теле цикла. В первой программе из-за дополнительного ++i получаем 0 2 4. В forc имя i служит константной ссылкой на счётчик. Через неё можно прочитать значение, а попытка выполнить ++i вызовет ошибку компиляции. В рабочем варианте счётчик увеличивается в заголовке, и выводится 0 1 2 3 4.

Второе различие касается верхней границы. В обычном for условие i < n проверяется перед каждым проходом с текущим значением n. Во второй программе после первого прохода n становится равно 2, поэтому выводится 0 1. В forc начальное значение n заранее копируется в end. В end остаётся 4, поэтому выводится 0 1 2 3. В обоих примерах forc записан через его раскрытие из условия.

```
int main() {
    for (int i = 0; i < 5; ++i) {
        cout << i << " ";
        ++i;
    }
    cout << endl;

    int counter = 0, end = 5;
    for (const int &i = counter; i < end; ++counter) {
        cout << i << " ";
        // ++i;  // При раскомментировании возникнет ошибка.
    }
    cout << endl;
}
```

```
int main() {
    int n = 4;
    for (int i = 0; i < n; ++i) {
        cout << i << " ";
        n = 2;
    }
    cout << endl;

    n = 4;
    int counter = 0, end = n;
    for (const int &i = counter; i < end; ++counter) {
        cout << i << " ";
        n = 2;
    }
    cout << endl;
}
```

*Напишите программу на языке* **Python** *для проверки того, что все числа во введенной 
последовательности неотрицательные. Если в цикле будет найдено отрицательное число, цикл должен
прерваться и вывести найденное число. Если отрицательных чисел нет, то вывести некоторое сообщение об этом.*

*Программа должна использовать конструкцию* **for break else**.

*Запишите аналогичную программу на С++. Какие изменения в алгоритме решения в ней появились?. Почему?*

*Написанные программы сохраните в папку с номером задания.*

Программа перебирает числа по порядку. При первом отрицательном числе она выводит его и выполняет break. В Python блок else относится к циклу и выполняется, только если перебор закончился без break. В C++ у цикла нет такого блока, поэтому переменная found запоминает, было ли найдено отрицательное число.

В Python блок else относится к циклу for. Если встретилось отрицательное число, программа печатает его и выходит через break. Если цикл дошёл до конца, выполняется else. В C++ у цикла нет блока else, поэтому добавляем переменную found. Она запоминает, нашли ли мы отрицательное число. В обе программы числа вводятся одной строкой через пробел.

```
numbers = [int(t) for t in input().split()]
for x in numbers:
    if x < 0:
        print(x)
        break
else:
    print("Отрицательных чисел нет")
```

```
int main() {
    string line;
    getline(cin, line);
    istringstream numbers(line);
    int x;
    bool found = false;
    while (numbers >> x) {
        if (x < 0) {
            cout << x << endl;
            found = true;
            break;
        }
    }
    if (!found)
        cout << "Отрицательных чисел нет" << endl;
```

A = { (x,y)| x ∈ [5;∞), y ∈ [-5;∞)}.

оль получается при x ≥ 5 и y ≥ −5. Единица получается во всей левой полуплоскости, а справа от неё — ниже соответствующей границы. Двойка остаётся в полосе от x = 0 включительно до x = 5 исключительно при y ≥ 0.

###  Задание 9 **(3)**
*Напишите программу на языке Python для решения следующей задачи.*

*Задана пронумерованная последовательность логических значений* **t(0), t(1), ..., t(n)**, **t(i) ∈ {False, True}**

*Последовательность обладает следующим свойством: существует некоторое число k такое, что 
все значения* **t(0), t(1), ..., t(k-1)** *равны* **False**, *а все значения* **t(k), ..., t(n)** *равны* **True**,
*то есть слева от* **k** *находятся значения* **False**, *а справа* - **True**. *Последовательность задается
функцией* **t(i)**, *которая возвращает логическое значение. Например, для тестирования эту функцию можно
задать следующим образом.*
```
def t(i):
   return i >= 1000
```

*Требуется написать программу, которая найдет число* **k**. *Программа должна реализовывать алгоритм 
бинарного поиска. Диапазон поиска задается переменными* **left** и **right**. *На каждом шаге вычисляется
центр диапазона, значение в нем проверяется, после чего диапазон сокращается в два раза.*

*Алгоритм должен быть записан через цикл* **while** *и реализовывать инвариант цикла*

t(left)=False ∧ t(right)=True

```
left = -1
right = 10**18
while ...:
   mid = ...
   if t(mid):
      ...
   else:
      ...
print(...)
```
Слева сохраняем позицию со значением False, справа — со значением True. Если в середине получили True, переносим туда правую границу. Если получили False, переносим левую. Когда границы становятся соседними, right указывает на первое True. Для функции из задания программа выведет 1000.

```
def t(i):
    return i >= 1000

left = -1
right = 10**18
while right - left > 1:
    mid = (left + right) // 2
    if t(mid):
        right = mid
    else:
        left = mid
print(right)
```
