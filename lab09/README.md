*Напишите генератор, который для заданной последовательности*
**seq** *будет задавать последовательность из каждого второго элемента* **seq**.

```
def every_other(seq):
    ...
```
*Ниже приведены примеры использования генератра.*
```
>>> print (*every_other([10, 20, 30, 40, 50]))
10 30 50
>>> print(*every_other(range(10)))
0 2 4 6 8
>>> print(*every_other(iter(range(10))))
0 2 4 6 8

```
     
def every_other(seg):
    it = iter(seg)
    x = next(it, None)
    while x != None:
        yield x
        x = next(it, None)
        x = next(it, None)
print (*every_other([10, 20, 30, 40, 50]))

В коде функция iter создаёт итератор, а next получает очередной элемент последовательности. Генератор выдаёт текущий элемент через yield, затем дважды вызывает next: первый вызов пропускает следующий элемент, второй получает элемент для следующей выдачи. Поэтому из списка [10, 20, 30, 40, 50] получаются значения 10 30 50. При окончании последовательности next возвращает None, и цикл завершается. *Какие из указанных функций и методов Python соответствуют определению чистых функций?
В случае отрицательного ответа требуется дать пояснение.*

* **file.readline|** — *чтение строки из файла.*
* **len** — *определение длины строки или количества элементов в контейнере.*
* **list.append** — *добавление в список нового элемента.*
* **sum** — *нахождение суммы.*
* **sorted** — *построение сортированного списка.*
* **list.sort** — *сортировка списка.*
* **random.randint** — *генерация случайного целого числа.*
* *Разворот списка.*
```
def rev(x):
    return x[::-1]
```
* *Выбор нескольких элементов из хвоста списка.*
```
tail_len = 3
def tail(x):
    return x[-tail_len:]
```
Чистая функция зависит только от переданных аргументов и не изменяет внешние данные. Для обычных списков чисел к чистым относятся len, sum, sorted и rev: они возвращают результат, не изменяя исходный список. Методы append и sort не являются чистыми, поскольку изменяют список. Метод readline изменяет текущую позицию чтения файла. Функция randint может возвращать разные числа при одинаковых аргументах. Функция tail зависит от внешней переменной tail_len, поэтому тоже не является чистой. Если в sum или sorted передать итератор, они расходуют его элементы, поэтому в этом случае изменяют его состояние.

###  Задание 11 **(2)**
*Рассмотрите следующую функцию.*
```
def toint(fun):
    def wrapper(*args):
        return fun(*map(int, args))
    return wrapper
```
*Что передается в функцию* **toint**? *Что возвращает эта функция?*
*Что делает функция* **wrapper**?
*Придумайте несколько примеров использования* **toint**.

<img width="632" height="254" alt="image" src="https://github.com/user-attachments/assets/168b1c77-6c97-4a99-85a9-0b20b1be7a83" />

В функцию toint передаётся другая функция (например, сложение или умножение), а возвращает она новую функцию-обёртку wrapper. Сама wrapper берёт все переданные в неё значения, превращает каждое в целое число и отдаёт их обратно в исходную функцию для расчётов.
Например, так можно считать сумму или искать максимум из чисел, которые записаны текстом: toint(max)('4', '19', '8') вернёт 19, а toint(pow)(2.9, 3.7) отбросит дробные части и возведёт 2 в степень 3, получив 8.
